# PAW — Personal AI Workflow

A modular Personal AI Workspace.

**Keep sources, connect knowledge, continue work.**

[한국어](README.ko.md) · [Public direction and names](docs/PUBLIC-DIRECTION.md) · [Wiki preview](sites/wiki/README.md)

PAW publishes separate instances of its actual web applications with public role names and fresh data stores. Their existing UI and features are retained. PAW - Wiki is the central wiki and hub linking the independent sites. Personal usage data, private deployments and credentials are excluded.

The first local preview is **PAW - Wiki**, adapted from the latest verified Wiki42 Git main. No public deployment URL is available yet. Ikna, Alder, Cedar and Uman Wiki are outside the current plan; SWU is maintained separately.

The former six-role prototype and its selected modules remain historical reference work, not the public delivery architecture. Root build/test commands concern that prototype. Use the Wiki-specific instructions for this preview.

## PAW - Canvas

A visual workspace for exploring and composing documents, data, relationships, and workflows. The immediate foundation is a Markdown note-map with existing editing, Graph and Canvas capabilities. Shared PAW object/status views, reusable Tools embedded in Wiki or other Spaces, AI proposal review, JSON, charts and workflow execution are staged goals. [Identity, use cases, current foundation and roadmap](docs/CANVAS.md). Public port and deployment are pending.

Spaces are applications, Tools reusable capabilities, Objects shared source identities, and Core their integration contracts. Independent deployment does not require duplicate originals. Public instances remain isolated from private production data. Runtime names/icons may still reflect earlier preview decisions; this documentation update does not implement them.
