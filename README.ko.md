# PAW — Personal AI Workflow

대화, 노트, 문서를 그때 쓰고 끝내지 않고 다음 작업에 이어 쓰기 위한 개인 AI 작업공간입니다.

[English](README.md) · [설계 방향](docs/DESIGN.md) · [작성자](https://github.com/juho-kim-dev)

필요한 자료가 AI 대화, 노트, 브라우저 탭, 파일에 흩어져 있었습니다. 좋은 답변을 다시 찾으면 앞뒤 맥락이 빠져 있었고, 문서로 옮기면 관리할 사본이 하나 더 생겼습니다. PAW는 이 불편에서 시작했습니다.

작업마다 알맞은 **Space**를 두고, 각 앱은 독립적으로 사용할 수 있게 만듭니다. 대화에서 노트로, 노트에서 위키 문서로, 문서에서 파일로 이어갈 때 출처와 맥락도 함께 가져가는 것이 목표입니다.

프로젝트 이름은 **Personal AI Workflow**입니다. **Personal AI Workspace**는 PAW가 지향하는 제품의 종류를 설명합니다. 이 저장소는 공개 소개와 설계 기록을 담으며, 제품 소스 공개는 별도로 준비하고 있습니다.

## 지금 둘러볼 공간

현재 공개 데모 작업은 아래 다섯 Space를 중심으로 진행합니다. 사이트별 공개 상태와 제공 범위가 다릅니다. 상태 기준은 2026년 10월 30일입니다.

| Space | 하는 일 | 데모 상태 |
| --- | --- | --- |
| [Notes](https://paw-notes.nonamegptpro.chatgpt.site/) | 노트를 쓰고 링크를 따라 생각을 정리합니다. | 공개 · 예제 노트, 브라우저별 저장과 초기화 |
| [Office](https://paw-office.nonamegptpro.chatgpt.site/) | HWP·HWPX 문서를 열고 편집합니다. | 공개 · 문서 작업은 브라우저 안에서 처리 |
| [Yarns](https://paw-yarns.nonamegptpro.chatgpt.site/) | 대화를 보관하고 검색하며 특정 메시지를 다시 읽습니다. | 공개 · 로그인 없이 예시 대화 읽기와 검색 |
| [Wiki](https://paw-wiki.nonamegptpro.chatgpt.site/) | 지식을 문서로 쓰고 연결하며 PAW의 다른 공간을 안내합니다. | 공개 · 데모 편집 내용은 브라우저에 저장 |
| [Study](https://paw-study.nonamegptpro.chatgpt.site/) | 문서를 나란히 읽고 학습 기록과 단어를 정리합니다. | 공개 · 샘플 논문 2편과 각 첫 2쪽의 한국어 대역 |

Yarns의 예시 서재는 읽기 전용이며, 로그인하면 별도의 개인 서재를 사용합니다. Notes는 예제 노트 5개로 시작하며 방문자의 브라우저마다 변경 내용을 따로 저장합니다. Study의 나머지 쪽은 원문으로 읽을 수 있으며 자동 번역은 연결하지 않았습니다. 브라우저에 저장하는 편집·개인 자료는 다른 방문자와 공유되거나 기기 사이에서 동기화되지 않습니다.

## 함께 만들 공간

아래는 PAW의 확장 방향입니다. 현재 공개된 데모 목록과는 구분합니다.

| Space | 역할 |
| --- | --- |
| Library | 글, 미디어, 참고 자료, 오픈소스 프로젝트를 모으고 분류합니다. 자료의 맥락을 보존해 탐색·조사·분석으로 이어갑니다. |
| Boards | 핀을 시각적인 컬렉션으로 모아 비교하고 계획합니다. |
| Forum | 글과 답글로 문서·아이디어를 논의하고 외부 커뮤니티 자료도 보관합니다. |
| Git | 저장소, 이슈, 개발 프로젝트를 다룹니다. Gitea 기반 작업공간을 검토하고 있습니다. |
| Studio | 이미지·영상·오디오를 편집하는 후속 공간입니다. |

Canvas라는 이름으로 논의했던 시각적 작업공간은 현재 앱 이름인 Notes로 소개합니다. 링크·그래프·기본 캔버스를 제공하며, 더 넓은 도식·워크플로 기능은 개발 방향으로 남아 있습니다.

## 공간을 연결하는 방식

**Spaces**는 작업하는 공간, **Tools**는 읽기·편집·검색·그래프 같은 기능, **Objects**는 대화·메시지·문서·파일·토론 같은 기록입니다. **Core**는 식별자, 참조, 판, 접근 권한을 함께 다루기 위한 규칙을 뜻합니다.

다른 공간에 표시하더라도 같은 기록은 같은 기록으로 다룹니다. 위키가 대화를 인용하면 보관된 대화의 메시지와 판을 가리킵니다. 분석·번역·수정 제안은 원본과 구별해 남깁니다. 원문을 요약문으로 덮어쓰거나 복사본마다 서로 다른 정본이 생기지 않게 하려는 설계입니다.

대화의 근거를 위키에 연결하고, 정리한 문서를 Office에서 파일로 만드는 흐름을 우선 생각하고 있습니다. [영문 구조도](README.md#how-the-pieces-fit)는 이 목표를 보여줍니다. 현재 앱의 저장소와 권한은 각각 운영되며, 공간 사이의 연결이 모두 완성된 상태는 아닙니다. 공통 규칙도 설계 중이고 하나의 DB를 쓰는 것으로 확정하지 않았습니다. [설계 방향 더 읽기](docs/DESIGN.md).

## 개발에서 다루는 문제

AI의 도움을 받아 앱 동작을 설계하고, 기존 소프트웨어를 확장하고, 웹 화면과 AI 도구를 연결합니다. 저장·재시도·충돌 뒤에도 자료가 유지되는지 확인하는 데 중점을 둡니다.

- **대화 보관:** 원본 판과 메시지 링크를 유지하고, 중단된 수집을 이어갈 때 중복 저장을 막습니다.
- **지식 편집:** 수정 제안이 어느 판을 기준으로 했는지 확인해 오래된 제안이 최신 문서를 덮어쓰지 않게 합니다.
- **노트 복구:** 미저장 초안을 보존하고 원문·판을 확인한 뒤 복구합니다. 충돌한 내용은 별도 사본으로 남깁니다.
- **문서 편집:** 화면과 AI 도구가 같은 문서 명령을 사용하며, 저장한 HWPX를 다시 열어 결과를 확인합니다.

각 기능은 제품별 구현에 나뉘어 있고 공개 데모가 전부 제공하지는 않습니다. 문서 검사에는 8쪽·16셀 HWPX 사례가 포함되며, 모든 형식과 문서를 호환한다는 의미는 아닙니다.

제품에 따라 TypeScript·JavaScript, React, Node.js, Cloudflare Workers, SQLite/D1, MCP·WebMCP를 사용합니다. Office는 기존 오픈소스 HWP/HWPX 편집기를 확장합니다. 제품 소스를 공개할 때 원본 출처·라이선스, 실행법과 재현 가능한 검사를 함께 정리합니다.

## 다음 작업

먼저 다섯 데모의 방문자 경험과 소스 공개를 정리합니다. 공간 간 연결은 Yarns의 대화 근거를 Wiki에서 참조하고, 판을 확인하는 수정 제안을 거쳐, Office에서 저장 후 다시 열 수 있는 문서를 만드는 흐름부터 검증할 계획입니다.

개인 기록, 비공개 대화, 배포 자격증명은 공개 저장소와 데모에 넣지 않습니다. 기존 링크를 유지하기 위해 저장소 이름 `personal-ai-workspace`는 그대로 사용합니다.
