# Personal AI Workspace (PAW)

**원문을 남기고, 맥락을 연결하고, 작업을 이어갑니다.**

[English](README.md) · [구조와 개발 순서](docs/ARCHITECTURE.md) · [CV 근거·한계](docs/CV-EVIDENCE.md) · [부계정 배포](docs/DEPLOY-SITES.md)

AI 보조로 개발한 개인 도구의 기존 구현을 선별 공개하는 저장소입니다. 공개 대상은 **서로 독립된 데모 사이트 6개**입니다. **안내·랜딩 사이트와 통합 앱은 만들지 않습니다.** 설명과 추후 데모 바로가기는 README가 맡습니다.

| 데모 | 활용할 기존 구현 | 독립 사이트 상태 |
| --- | --- | --- |
| 대화 기록 | 원문 검색·유니코드 강조·문맥·버전 고정 링크 | 분리 구현·검증 대기 |
| 노트 작업실 | 메타데이터·그래프·JSON Canvas·초안 복구 | 분리 구현·검증 대기 |
| 지식·보고서 | 근거·제안 계약과 문서 버전에 따른 검토 | 분리 구현·검증 대기 |
| 문서 편집 | 구조화 명령·보존 검사·패치된 HWPX 엔진 | 분리 구현·검증 대기 |
| 자료 보드 | 보드·자료·분류 검증 | 분리 구현·검증 대기 |
| 미디어 보관함 | 코퍼스 검색·영상 시점 이동·이미지 탐색 | 분리 구현·검증 대기 |

각 앱의 실제 구현과 화면을 가능한 범위에서 재사용하고 개인 자료를 합성 예제로 교체합니다. 핵심 코드 선별을 여섯 앱 전체의 이식 완료로 표현하지 않습니다. 공개 화면에는 역할명을 사용하며 개인 사이트·문서·전체 대화·운영 DB·인증값은 공개하지 않습니다. SWU는 별도 작업입니다.

## 현재 상태 — 2026-10-29

앞서 만든 화면은 여섯 역할을 한 앱에 합친 시제품이었습니다. **이 구성은 채택되지 않았으며 공개 배포 대상이 아닙니다.** 검증한 동작을 추출할 수 있도록 코드를 임시 보존하지만 통합 화면·스크린샷·공유 상태를 여섯 독립 사이트의 완성 근거로 사용하지 않습니다. 각 사이트의 진입점·상태·빌드·배포 패키지는 분리 구현해야 합니다.

아래 명령은 아직 **기존 통합 시제품만** 실행합니다. Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm test
npm run build
npm start
```

미리보기는 `http://127.0.0.1:4173`입니다. 문서 편집은 메모리에 있으므로 해당 화면을 떠나기 전에 내려받아야 합니다. `package:sites`는 통합본 배포를 막기 위해 중단하도록 바꿨습니다. 이전 전달 폴더·ZIP도 사용하지 않습니다. 여섯 독립 사이트의 배포 준비·실제 게시 완료는 아직 주장하지 않습니다.

## 소스와 근거

- `components/`: 기존 핵심 코드. `provenance.json`에 출처 commit·원본/선별본 해시·변환 이유를 기록합니다.
- `src/`, `assets/`: 합성 자료·직접 만든 이미지/영상·어댑터·기존 통합 시제품.
- `tests/`: 동작과 실제 WASM 검사. [검증 기록](docs/VALIDATION.md)은 시제품 결과와 앞으로 필요한 독립 사이트 검증을 구별합니다.
- `docs/`: 구조·출처·배포 수락 조건·[CV 근거](docs/CV-EVIDENCE.md).
- `sites/`: 중립 설정 참고본. 여섯 사이트의 배포 패키지는 아닙니다.

`npm run check:public`은 선별 파일 해시와 알려진 개인 정보 패턴을 검사합니다. 임의의 추가 자료까지 안전하다고 보장하지는 않습니다. GitHub Actions 중지는 유지합니다.

빌드 후 `node <저장소 절대 경로>/dist/mcp.mjs`로 합성 자료를 읽는 로컬 MCP 예제를 실행할 수 있습니다. 브라우저 편집·개인 앱·실제 모델에는 연결되지 않습니다. AI 수정안과 미디어 주석은 직접 작성한 예시입니다.
