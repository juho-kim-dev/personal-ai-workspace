# Personal AI Workspace (PAW)

**원문을 남기고, 맥락을 연결하고, 작업을 이어갑니다.**

[English](README.md) · [구조와 개발 순서](docs/ARCHITECTURE.md) · [성과 설명의 근거·한계](docs/CV-EVIDENCE.md) · [부계정 Sites 배포](docs/DEPLOY-SITES.md)

대화·노트·지식·문서·자료 보드·미디어를 다시 활용하기 위해 AI 보조로 개발한 개인 도구 모음입니다. 기존 구현에서 선별한 핵심 코드와 **여섯 역할을 실제로 체험하는 공개 참조 데모**를 담았습니다. 공개 화면의 자료는 모두 직접 작성한 합성 예제입니다.

기존 앱들은 각자의 데이터 구조와 저장소를 유지합니다. 이 데모는 선택한 기능을 정적 웹 화면에 연결한 공개 예제이며, 개인 작업공간이나 공통 운영 DB를 공개한 것이 아닙니다.

![공개 참조 데모](docs/screenshots/overview.jpg)

## 실행

Node.js 22.13 이상에서:

```sh
npm ci
npm test
npm run build
npm start
```

`http://127.0.0.1:4173`을 엽니다. 로그인·API 키·DB·비공개 소스가 필요하지 않습니다. 문서 엔진은 문서 역할을 열 때 읽습니다. 노트·캔버스·보고서·보드 변경은 이 탭에 저장되며, 미저장 노트 초안은 브라우저 복구 기록에도 남습니다. 문서 편집은 메모리에 있으므로 화면을 떠나기 전에 HWPX를 내려받으세요.

## 여섯 역할

| 역할 | 공개 데모에서 해볼 수 있는 일 | 재사용한 구현 |
| --- | --- | --- |
| 대화 기록 | 원문 검색, 앞뒤 맥락, 버전이 고정된 메시지 링크 | 유니코드 검색·강조·경로·문맥 |
| 노트 작업실 | 글쓰기, 노트 연결, 그래프·캔버스 편집, 초안 복구 | 메타데이터·그래프 UI·JSON Canvas·초안 저널 |
| 지식·보고서 | 관측 기록, 수정안 검토·반영, 오래된 수정안 차단 | 근거·제안 입력 계약과 새 공개용 상태 어댑터 |
| 문서 편집 | 본문·표 셀 수정, 첫 페이지 렌더링, HWPX 저장·다시 열기 | 구조화 명령·실패 시 미반영·선택 서식 검사·패치된 MIT 엔진 |
| 자료 보드 | 자료 묶기, 즐겨찾기, 메모, 보드 생성 | 기존 보드·자료·분류 검증 |
| 미디어 보관함 | 설명·작성된 주석 검색, 영상 2초 이동, 이미지 묶음 탐색 | 기존 코퍼스 검색·영상 및 캐러셀 조작 |

예제 프로젝트는 「느리게 보는 도시」 전시 기획입니다. AI 수정안과 영상 주석은 **직접 작성한 예시**로 표시하며, 실제 모델 호출·원격 수집·개인 계정 연결은 없습니다.

## 공개 범위와 근거

- `components/`: 기존 핵심 코드. `provenance.json`에 출처 commit·원본/선별본 해시·변환 이유를 기록했습니다.
- `src/`, `assets/`: 새 공개 UI·합성 자료·브라우저 저장 어댑터·직접 만든 이미지/영상.
- `tests/`: 유니코드·링크·그래프·캔버스·초안 보존·수정안 충돌·보드·미디어·MCP·실제 HWPX 검사.
- `docs/`: 구조·출처·검증 기록·CV에 사용할 수 있는 설명과 남은 개발.
- `sites/`: 부계정 배포용 중립 설정. Site ID나 자격증명은 없습니다.

문서 엔진은 [rhwp](https://github.com/edwardkim/rhwp) 기반이며 기존 패치와 MIT 출처를 보존했습니다. 엔진 전체의 독자 개발이나 모든 문서의 완전 호환을 주장하지 않습니다. [선별·변환 범위](docs/PROVENANCE.md)와 [실제 검증](docs/VALIDATION.md)을 참고하세요.

## MCP와 배포

빌드 후 MCP 클라이언트에서 `node <저장소 절대 경로>/dist/mcp.mjs`를 실행하면 여섯 역할 읽기와 대화 검색 도구를 사용할 수 있습니다. **합성 자료를 읽는 로컬 예제**이며 브라우저 편집 내용이나 개인 앱에 연결되지 않습니다.

`npm run package:sites`는 부계정으로 전달할 정적 파일과 해시 목록을 `.local/sites-ready/`에 만듭니다. [배포 인계](docs/DEPLOY-SITES.md)에 따라 부계정 Sites 연결에서 새 사이트를 생성·게시합니다. 현재는 소스와 배포 준비 단계이며, 실제 공개 URL이나 배포 완료는 주장하지 않습니다.

GitHub Actions는 중지 상태를 유지합니다. 로컬 검사·원격 CI·main 반영·배포를 구분합니다. 기존의 수집 재개·8쪽/16셀 사례 등 이번 공개본에서 재현하지 않은 설명은 [CV 근거 문서](docs/CV-EVIDENCE.md)에 별도로 표시했습니다.
