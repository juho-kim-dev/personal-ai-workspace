# Personal AI Workspace (PAW)

**사람과 AI가 대화·지식·문서를 보관하고 다시 활용하기 위한 개인 작업공간입니다.**

[English](README.md) · [작성자](https://github.com/juho-kim-dev)

AI 대화, 노트, 파일에 흩어진 자료를 다시 찾고 안전하게 수정하기 위해 개발한 독립 웹앱 모음입니다. AI 보조로 앱 동작, 자료 보존, 도구 연결과 검증을 개발했습니다. 앱별 데이터 구조와 저장소를 유지하며, 하나의 공통 DB나 완성된 자율 작업 플랫폼을 의미하지 않습니다.

## 만든 기능과 해결한 문제

| 영역 | 구현 내용 | 해결하려는 문제 |
| --- | --- | --- |
| 대화 보관·검색 | ChatGPT 공개 공유 링크 수집, 원본 판과 메시지 고유 링크 보존, 웹 화면과 MCP/WebMCP 읽기 | 사람과 AI가 같은 원문과 문맥을 다시 찾도록 함 |
| 수집 재개 | 작업 상태 저장과 재시도 중복 방지 | 수집 중단 후 처음부터 다시 시작하는 문제 |
| 지식 편집 | 문서 판에 연결한 수정 제안과 오래된 제안 거절 | 이전 수정본이 최신 내용을 덮어쓰는 문제 |
| 노트 복구 | 미저장 초안 보존, 복구 전 원문·판 확인 | 저장 실패와 충돌 상황에서 편집 내용 유실 |
| 문서 편집 | 오픈소스 HWP/HWPX 편집기 확장, 화면·AI 공통 명령과 저장 후 재열기 검사 | 입력 경로에 따라 편집 동작이 달라지거나 저장 결과가 손상되는 문제 |

위 기능은 여러 앱에 나뉘어 있으며 앱별 도구·읽기·쓰기 지원 범위가 다릅니다. [영문 소개의 구조도](README.md#design-overview)는 이 관계를 개념적으로 보여줍니다.

## 구체적인 개발 사례

- 수집 중단 시 저장된 상태에서 이어가고 이미 가져온 자료의 중복을 방지합니다.
- 문서 수정 제안의 기준 판과 현재 판을 비교해 오래된 제안 적용을 거절합니다.
- 서버 저장에 실패한 초안을 보존하고 복구 시 원문·판이 다르면 별도 사본으로 남깁니다.
- 문서 저장 후 재열기로 본문·표·선택 서식을 확인합니다. 기존 개발 기록에는 8쪽·16셀 HWPX 사례가 있으며 전체 형식 호환을 뜻하지 않습니다.

현재 공개 레포에는 이 검사들을 재현할 제품 코드와 시험 자료가 아직 포함되어 있지 않습니다.

## 기술과 공개 상태

앱별로 TypeScript/JavaScript, React, Node.js, Cloudflare Workers, SQLite/D1, MCP/WebMCP를 사용합니다. 문서 편집은 기존 오픈소스 편집기를 확장한 작업이며 전체 엔진을 독자 개발한 성과로 표시하지 않습니다.

**2026-10-28 첫 공개본:** 프로젝트 소개와 구조를 담은 문서 레포입니다. 아직 설치 가능한 배포본이나 공개 데모는 제공하지 않습니다.

합성 자료로 만든 화면·시연, 선별한 소스와 재현 예제, 구성요소별 실행법·검사 자료·외부 코드 출처 및 라이선스를 순차적으로 정리할 예정입니다. 개인 기록·비공개 대화·배포 자격증명은 공개 자료에 포함하지 않습니다.
